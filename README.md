u# 🎓 Sistem Kartu Ujian (Supabase + Cloudinary)

Aplikasi web sederhana untuk mengelola data kartu ujian siswa. Dibangun menggunakan arsitektur **PERN** (PostgreSQL via Supabase, Express, React, Node.js) dengan fitur upload gambar ke **Cloudinary**.

## 🚀 Fitur Utama

- **CRUD Data:** Membuat, Membaca, dan Menghapus data peserta ujian.
- **Image Upload:** Upload pas foto siswa ke Cloud storage (Cloudinary).
- **Database Realtime:** Penyimpanan data teks menggunakan Supabase.
- **Modern UI:** Antarmuka responsif dengan CSS custom.
- **User Feedback:** Notifikasi interaktif menggunakan SweetAlert2 (Loading state, Success alert, Confirm delete).

## 🛠️ Tech Stack

**Frontend:**
- React.js (Vite)
- Axios (HTTP Client)
- SweetAlert2 (Notifikasi)
- CSS3 (Custom Styling)

**Backend:**
- Node.js & Express
- Multer (File Handling)
- Cloudinary SDK (Image Storage)
- @supabase/supabase-js (Database Client)

## ⚙️ Prasyarat

Sebelum menjalankan proyek, pastikan Anda memiliki:
1.  **Node.js** terinstall di komputer.
2.  Akun **Supabase** (untuk database).
3.  Akun **Cloudinary** (untuk penyimpanan gambar).

---

## 🗄️ Setup Database (Supabase)

1.  Buka dashboard Supabase Anda.
2.  Masuk ke menu **SQL Editor**.
3.  Jalankan query berikut untuk membuat tabel:

```sql
CREATE TABLE kartu_ujian (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nama TEXT NOT NULL,
  nomor_ujian TEXT NOT NULL,
  jurusan TEXT NOT NULL,
  foto_url TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW())
);
